# Karen Schick – Portfolio Website

Welcome to the portfolio website of **Karen Schick**, a full stack web developer and photographer based in New Hampshire. This React-based site showcases professional projects, an about section, and a visually engaging photography carousel — all wrapped in modern animations and responsive design.

## 🌐 Live Site

[https://karenschick.github.io/portfolio-karenschick](https://karenschick.github.io/portfolio-karenschick)

---

## 🧩 Technologies Used

- **React** (with React Router for routing)
- **Framer Motion** – Animations and transitions
- **React Bootstrap** – UI components and layout
- **Modular Components** – Custom-built Carousel, Contact Form, Navigation
- **Deployed via** GitHub Pages

---

## 🔍 Features

### 🏠 Home Page
- Animated welcome section introducing Karen.
- Clickable elements to access Portfolio and About Me sections.
- Interactive profile photo with hover animation.

### 👩‍💻 About Me Section
- Dynamic text describing Karen’s journey into web development and photography.
- Smooth entry animations using Framer Motion.
- Embedded **Photography Carousel** (`AboutCarousel`) linking to Instagram.

### 🖼️ AboutCarousel Component
- A React Bootstrap carousel showcasing original wildlife and nature photography.
- Images include: loon, deer, lizard, foggy landscape, and flowers.
- Styled for smooth transitions and clean presentation.

### 📁 Portfolio Section
- A responsive grid of project cards.
- Each card includes a project image, description, and external link.
- Built with `motion.div` to animate on hover and tap.

### 🧭 Navigation
- A transparent, minimalist navbar built with React Bootstrap.
- Centered links to Home, About Me, Portfolio, and **Contact**.
- Contact button opens a **modal** with a built-in form.

### 📬 ContactForm Component
- Modal form with fields for name, email, and message.
- Styled with Bootstrap components.
- Captures input for future backend integration or email service.
